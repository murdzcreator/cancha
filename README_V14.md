# CANCHA V14 — Integración opcional SoccerData

La interfaz V13 y los escudos locales se mantienen. V14 agrega puente Python, importador validado de tablas y calendarios, paginación, fichas de partidos importados, estados corregidos y diagnóstico de fuentes.

**No se incluye SoccerData instalado ni se han extraído datos actuales de sitios de terceros.** Esta entrega es el código y los controles necesarios para importar datos de fuentes que permitan su uso. Los 183 clubes y 37 partidos de referencia se conservan.

Ve `GUIA_SOCCERDATA.md` e `INSTRUCCIONES.md`.

CANCHA V14.1: Premier League y LaLiga, importación CC0 desde OpenFootball; consulta README_V14_1.md.
